# ⚡ Mega Man Platformer (WIP)

A fast-paced, retro-inspired Mega Man style game built in Python + Pygame.  
Right now it’s a prototype — movement works, enemies exist, and the core engine is forming — but the full game is still under construction.

## 🧩 What’s Working
- Player movement + jumping
- Early animations
- Basic enemy behavior
- Collision system prototype

## 🔧 What’s Coming Next
- Shooting + projectile system
- Health bars + damage
- Boss mechanics
- Level design polish
- Sound effects + music
- Full sprite overhaul

## 🛠️ Tech
Python • Pygame • Custom pixel art

## 🎯 Purpose
This project is mainly for learning:
- Game loops  
- Animation pipelines  
- Collision systems  
- Level design  
- Clean Python architecture  

## ▶️ Run It
pip install pygame
python main.py


## 📝 Status
Not finished — expect rough edges, placeholder art, and experimental code.
